# 📊 Data Intelligence Dashboard — Excel Data Analysis Project

## 📌 Project Overview

**Data Intelligence Dashboard** is an advanced Microsoft Excel data-analysis project designed to transform raw customer transaction data into meaningful business insights.

The project combines **Excel formulas, KPI analysis, customer analysis, regional analysis, product analysis, What-If scenarios, linear regression, visualizations, and an interactive dashboard** into one complete data-analysis workflow.

The workbook demonstrates how Excel can be used as a powerful tool for **data analytics, business intelligence, reporting, and decision-making**.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze customer transaction data.
- Calculate important business KPIs.
- Analyze revenue across regions and categories.
- Identify top-performing products and customers.
- Analyze customer segments and payment methods.
- Build an interactive business dashboard.
- Perform What-If and scenario analysis.
- Use linear regression to identify revenue trends.
- Create visualizations for business reporting.
- Generate automated business insights and recommendations.
- Practice advanced Excel formulas and data-analysis techniques.

# 🔄 What-If Analysis

The **What-If & Regression** sheet contains a Scenario Manager for evaluating different business assumptions.

Three scenarios are included:

### 1. Pessimistic

- Sales volume change: **-10%**
- Price change: **-5%**
- Cost of goods: **70%**
- Operating expenses: **$60,000**

### 2. Base

- Sales volume change: **0%**
- Price change: **0%**
- Cost of goods: **65%**
- Operating expenses: **$55,000**

### 3. Optimistic

- Sales volume change: **+15%**
- Price change: **+5%**
- Cost of goods: **60%**
- Operating expenses: **$50,000**

## 📊 Scenario Results

| Scenario | Projected Revenue | Projected Profit |
|---|---:|---:|
| Pessimistic | $195,960 | -$1,212 |
| Base | $229,192 | $25,217 |
| Optimistic | $276,750 | $60,700 |

### Key Insight

The optimistic scenario produces significantly higher revenue and profit.

The pessimistic scenario results in a small operating loss, showing how sensitive profitability can be to changes in sales volume, pricing, costs, and operating expenses.

# 📈 Linear Regression Analysis

The workbook performs a linear regression using:

> **Monthly Revenue vs Month Number**

### Regression Metrics

| Metric | Value |
|---|---:|
| Slope | 159.50 |
| Intercept | 17,480.94 |
| R-Squared | 0.0213 |
| Correlation | 0.1459 |
| Standard Error | 4,091.24 |

### Interpretation

The very low **R-squared value of approximately 0.021** indicates that the simple month-number regression explains only a small portion of the variation in monthly revenue.

Therefore, factors other than a simple linear time trend are likely influencing revenue performance.
